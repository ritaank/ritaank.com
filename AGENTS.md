# Agent Instructions

- This is a Zola static site. Prefer small content/template/style edits over broad rewrites.
- Do not edit `public/`; it is generated by `zola build`.
- Homepage copy lives in `content/_index.md`; full bio lives in `content/about.md`.
- The homepage template is `templates/index.html`; shared layout is in `templates/base.html`; nav is in `templates/partials/nav.html`.
- Styles live in `sass/main.scss`.
- Before changing copy, preserve the site's concise, personal tone.
- After edits, run `zola build`.
- For local verification, run `zola serve --interface 127.0.0.1 --port 1111` and check `/`, `/about/`, `/blog/`, and `/admissions/`.
- Avoid unrelated formatting churn.
